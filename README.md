# Gestion des Gares de France

Ce projet est un logiciel développé en .NET permettant de répertorier et d'afficher les gares de France, classées par région et par type (gare de voyageurs, gare de triage, etc.). Ce logiciel est destiné aux passionnés de ferroviaire et aux professionnels souhaitant explorer les infrastructures ferroviaires françaises.

## Fonctionnalités

* Affichage des gares par région
* Filtrage par type de gare (voyageurs, triage, fret, etc.)
* Recherche rapide par nom ou région
* Interface conviviale et intuitive

## Technologies utilisées

* .NET
* WPF (Windows Presentation Foundation) pour l'interface utilisateur
* Base de données locale pour le stockage des informations

## Installation

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/AzmogEx/gestion-gares-france.git
   ```
2. Ouvrir le projet avec Visual Studio
3. Restaurer les packages NuGet
4. Lancer l'application depuis Visual Studio

## Utilisation

1. Sélectionner une région pour afficher les gares associées
2. Utiliser la barre de recherche pour trouver une gare spécifique
3. Filtrer par type de gare pour affiner la recherche
